# uml-viewer-neo

`umlv` turns a Go, TypeScript or Python repository into one HTML page: the
folders and files as boxes, their imports as arrows, and a lamp on each box
showing how risky it is to change.

Status: design. Nothing to run yet. Start with
[docs/design/architecture.md](docs/design/architecture.md).

Private: the ideas come from unclebob's unlicensed
[uml-viewer](https://github.com/unclebob/uml-viewer), so this repo is not
published.
